READ BEFORE COMPARING

        
A benchmark for musical video playback.

        

          This is an interactive browser benchmark, not a unit-test runner. It
          uses identical media and seeded schedules to exercise clip switching,
          position jumps, repeated stutters and speed remapping. Unit tests
          separately validate the scheduler and resource lifecycle.
        

        
Four strategies, one presentation surface

        

          Every adapter presents through WebGPU. The HTML pool baseline is
          adapted from Beatmaxxer's actual prewarm/commit/seek strategy.
          Mediabunny uses WebCodecs with a bounded image cache. The fully
          resident bank decodes once and stores GPU textures. libmedia is
          withheld from scoring until seeking, decoder identity and frame
          timestamps can be verified together.
        

        
Compare like with like

        

          Match media hashes, audio/grid hashes, deck count, resolution, seed,
          workload, duration, revision, memory budget and cache conditions. A
          large resident GPU bank trades preload time and memory for runtime
          responsiveness. It is not a language benchmark.
        

        
What the included runs establish

        

          The reference workstation previews showed responsive resident-texture
          playback, including eight switching decks and independent ramps. They
          do not constitute three repeated two-minute trials per configuration
          or the planned ten-minute soak. Older revisions use different
          observation boundaries and are labeled legacy. libmedia's failed
          probes remain visible.
        

        
Timing and visibility

        

          AudioContext drives the transport. Frame timestamps and WebGPU
          submission estimate presentation; they do not measure screen scanout
          or acoustic delay. Native media cadence and 24fps remapping output are
          distinct from display refresh rate. Hidden-tab and paused runs are
          invalid for comparison.
        

        
Use your own machine

        

          Clone the repository, install dependencies with Bun, and run the
          benchmark command described in the README. Included Redline media and
          analyzed events work without another repository or an analysis
          service. You can import exported runs here and export the filtered
          table as CSV or print it.
